# JAM - Flutter アプリ

保存した場所・地図・口コミ投稿・プロフィールを管理する旅行口コミアプリ「JAM」の
Android向けFlutter実装です。5枚のデザインカンプ（保存した場所／プロフィール／地図／
口コミ詳細／口コミ投稿）をもとに作成しています。

## ⚠️ 重要：このまま実行する前に

本プロジェクトは **Flutter SDKがインストールされていない環境** で作成したため、
`flutter pub get` や実機・エミュレータでの動作確認は行えていません。
コードは注意深く記述していますが、初回セットアップ時に以下の手順を必ず実行してください。

## セットアップ手順

1. このフォルダ（`jam_app/`）をFlutterがインストール済みのPCに配置します。
2. ターミナルでこのフォルダに移動し、Android/iOSなどのプラットフォームフォルダを生成します。
   （`lib/` や `pubspec.yaml` は上書きされず、不足しているプラットフォームフォルダのみ追加されます）

   ```bash
   flutter create .
   ```

3. 依存パッケージを取得します。

   ```bash
   flutter pub get
   ```

4. 実機・エミュレータを接続し、実行します。

   ```bash
   flutter run
   ```

5. Android APKをビルドする場合：

   ```bash
   flutter build apk --release
   ```

## 実装内容と動作の対応

- **保存した場所（画像1）**：カテゴリーチップで絞り込み、ブックマークアイコンで保存解除、
  カードタップで口コミ詳細へ遷移します。
- **プロフィール（画像2）**：保存数／投稿数／参考になった数はローカル保存データから自動集計。
  鉛筆アイコンから表示名・アバターカラーを編集可能。各設定項目は個別画面に遷移します。
- **地図（画像3）**：ネットワーク地図の代わりに`CustomPainter`で簡易マップを描画し、
  デザイン通り吹き出しコメントを地図上に固定表示。吹き出しタップで該当スポットの
  口コミ詳細を開きます。検索バー・フィルターチップ・通知バナー・「＋」投稿ボタンも
  すべて動作します。
- **口コミ詳細（画像4）**：地図を背景にしたシートに口コミ一覧を表示。「続きを読む」の
  開閉、「いいね」タップでの参考になった数の加算、「…」メニューからの報告・共有が動作します。
- **口コミ投稿（画像5）**：位置情報編集、カテゴリー選択、星評価、文字数カウント、
  写真追加（最大5枚のプレースホルダー）、投稿ボタンが動作し、投稿内容はローカルに
  永続化されてプロフィールの投稿数にも反映されます。

## データの永続化について

`shared_preferences` パッケージを使用し、保存したスポット・投稿した口コミ・
100mアラート設定・言語設定・プロフィール情報を端末内にJSON形式で保存しています。
アプリを再起動してもデータは保持されます。

## 状態管理について

Provider / Riverpod などの外部パッケージは使わず、Flutter SDK標準の
`ChangeNotifier` + `AnimatedBuilder` のみでシンプルに画面間のデータ同期を行っています
（`lib/state/app_data.dart`）。
